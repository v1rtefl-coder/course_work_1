# Курсовая работа 1

## Описание проекта
Это приложение для анализа банковских транзакций, которое предоставляет:
1. Анализ расходов по банковским картам
2. Актуальные курсы валют через API
3. Цены на акции S&P 500
4. Поиск транзакций по описанию и категориям
5. Генерацию отчетов о тратах

## Установка и запуск
### Клонировать репозиторий
```
git clone https://github.com/your-username/course-work-1.git
cd course-work-1
```
## Требования
- Python 3.9+
- Poetry


## Установка зависимостей
```
poetry install
```
## Активировать виртуальное окружение
```
poetry shell
```

## Настроить переменные окружения
```
cp .env.example .env 
```

## Подготовить данные

1. Поместите файл с транзакциями operations.xlsx в папку data/
2. Убедитесь, что файл содержит необходимые колонки

## Запуск приложения
```
python main.py
```
